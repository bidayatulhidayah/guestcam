# v0.1 — Phase 0 skeleton

- **Date:** 2026-10-27
- **Tag:** `v0.1`
- **Previous version:** v0.0
- **Phase:** Phase 0 (Setup)

## Goal

An empty but correctly structured skeleton that runs against the Firebase emulators, passes its tests and deploys to a Hosting preview channel that opens on a phone. No guest features yet.

## What shipped

- Guest-facing:
  - Placeholder pages for every route: permanent link `/s/:publicId`, alias `/:aliasName`, event entry (`tunang-K7Q2` shows the parsed slug and code, otherwise the generic code screen), gallery, `/mine` and the neutral "alias inactive" page. Each page shows its name in both languages.
  - Bahasa Melayu by default with a one-tap English switch that is remembered on the device.
  - Design tokens (paper, ink, one olive accent), self-hosted Atkinson Hyperlegible and Instrument Serif (56 KB), and the base Button, Tile and Screen components.
  - Footer on every screen: "© 2026 Hidayah. Hak cipta terpelihara.", app version, and a "Lapor Masalah" placeholder.
  - Installable app shell (PWA): reopens offline; a new version is applied at the next screen change, never mid-screen.
- Host-facing:
  - `/login` and `/admin` placeholders, loaded as separate chunks that guests never download.
- Internal / technical:
  - npm workspaces monorepo (`shared`, `web`, `functions`, `rules-tests`), TypeScript strict, Node 24.
  - `shared/`: data model types, Firestore and Storage path builders, `parseEntry`, permanent link vs alias detection, per-plan limits, feature catalog with packages and `isFeatureAvailable`.
  - Firebase config (Firestore, Storage, Functions `nodejs24` in asia-southeast1, Hosting SPA rewrite and cache headers), deny-all rules, emulators on the `demo-guestcam` project, a `ping` function.
  - Storage adapter interface with a Firebase stub (AGENTS.md rule 9).
  - Web app connects to the emulators in development with Anonymous Auth; the Firebase SDK is a lazy chunk.
  - Scripts: `dev`, `emulators`, `seed`, `test`, `typecheck`, `build`, `deploy:preview`; dev seed for spaces #00000, #00001 and #10001.
  - Full product spec in `docs/product/spec.md`; decisions D-047 to D-055 in memory.md.

## Known issues

- On Windows, `firebase emulators:exec` (so `npm test`) and stopping `emulators:start` can leave the Firestore emulator (`java.exe`) holding port 8080. Close it in Task Manager before the next run.
- `npm run test:rules` prints a harmless Java NullPointerException from the storage rules runtime at shutdown.
- Parts of `docs/product/spec.md` (early URL examples, data model sketch, "Claude Code setup") are superseded by AGENTS.md, architecture.md and memory.md; two of its links point to `docs/architecture.md` instead of `docs/architecture/architecture.md`.
- The app icon is a placeholder until the product name is final.
- Not deployed to production; only the `preview` channel exists.

## Rollback

How to roll back: redeploy tag `v0.0` (documentation only, no app). Notes: nothing is in production, so there is nothing to roll back in Hosting.
